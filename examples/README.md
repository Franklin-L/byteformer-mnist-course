# 教师实测结果

这些文件是 2026-09-12 本地实际运行的记录，供查看效果与核对流程。学生应提交自己的结果。

**正式课程看 `course_baseline/` 和 `course_full_test/`：50,000张训练、1,000张验证，计划8轮、验证选中第5轮，完整10,000张测试准确率97.07%（9707/10000）。**

原训练先评估1,000张，完整10,000张由同一已锁定模型单独评估；历史记录保持原样。发布版默认在训练末直接评估全部10,000张。后期学习率在第4、6轮结束乘0.2。训练712.90秒，全测另5.93秒。

以下为开发时的早期快速演示记录，保留用于追溯，**不作为当前正式配置或达标成绩**。

| 目录 | 设置 | 最佳验证准确率 | 测试准确率 |
| --- | --- | --- | --- |
| baseline | 6000训练 / 1000验证 / 1000测试，3轮 | 88.50% | 88.60% |
| epochs5 | 与baseline仅轮数不同，5轮 | 90.40% | 89.50% |
| full_test | baseline最佳模型，官方完整10000测试图 | 沿用baseline | 88.72% |
| cpu_smoke | 1000训练 / 200验证 / 200测试，CPU 1轮 | 26.50% | 20.50% |

基线与5轮实验的前3轮训练损失及验证准确率逐项一致，二者都从同一官方预训练权重与相同随机种子开始。
`best.pt` 由验证准确率选择。完整测试集由已选好的3轮基线模型独立评估，不再调参。
`metrics.json`、`history.csv`、预测数组、数据索引和控制台日志保留实际值；绘图来自这些保存的预测与指标。

GPU训练设备为 NVIDIA GeForce RTX 4090。基线39.48秒、5轮57.67秒为本机脚本计时，含数据转换/读取、训练、验证和最终测试，不含安装、下载及末尾出图。
CPU验证使用 AMD EPYC 7763 的4个计算线程，计时65.68秒左右，以JSON中的原始值为准。
Kaggle和AutoDL的网络、硬件与软件可能不同；本仓库没有将这些本地记录标注为云平台实测。

预测图的选样方式为“测试子集前12张 + 最多4个额外错例”，图中正确率不能当作整体测试准确率。
