# 后续课件内容安排

当前阶段不生成新 PPT。后续制作时按照下面的内容层次组织，避免把通用字节模型与损坏码流应用论文混在一起。

## 基础部分

1. 多媒体通信：信源、编码、信道、受损码流和接收端。
2. Gilbert–Elliott 二状态模型。
3. JPEG 与 H.264 码流基本结构，以及结构受损对解码的影响。
4. 字节模型发展：MEGABYTE、MambaByte、bGPT、mBLM，可补充 ByT5 和 Byte Latent Transformer。
5. ByteFormer：选择理由、输入形式、序列缩减、Transformer 编码器和分类头。
6. MNIST 码流分类实验：数据划分、环境、训练、验证和测试。

## 加分项页面

1. 课程提供的 bit flip、byte loss 和 mixed 损坏测试集。
2. 干净训练模型在受损测试上的准确率下降。
3. 损坏增强、预测一致性和特征对齐等可选改进。
4. CBSU-ALLM、BRACE、BSCV、ByteAction、Cibic、VUB 作为辅助参考资料。

字节模型介绍页不放 CBSU-ALLM、BSCV 或 BRACE；这些工作只在损坏码流加分项页面出现。
